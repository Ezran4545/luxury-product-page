# Luxury Product Page

A modern, responsive e-commerce product page for a luxury watch brand, built with vanilla HTML, CSS, and JavaScript.

## Live View

[View Live Demo](https://YOUR_GITHUB_USERNAME.github.io/luxury-product-page/)

> Replace `YOUR_GITHUB_USERNAME` with your actual GitHub username after publishing with GitHub Pages.

## Features

- Premium product page layout and typography
- Dark/light theme toggle
- Interactive image gallery with popup lightbox
- Zoom controls, wheel zoom, pinch-to-zoom, and drag-to-pan
- Product variants (size and color chips)
- Add-to-cart interactions with quantity sync (desktop/mobile)
- Sticky mobile buy bar
- Sticky mini-cart summary with subtotal
- Wishlist toggle
- Reviews section with rating filters
- Recently viewed products section

## Project Structure

- `index.html` - page structure
- `styles.css` - all styling and responsive rules
- `script.js` - interactivity and UI behavior

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

## Deployment (GitHub Pages)

1. Push this project to a GitHub repository named `luxury-product-page`.
2. In GitHub, go to **Settings > Pages**.
3. Under **Build and deployment**, choose:
   - **Source**: Deploy from a branch
   - **Branch**: `main` (root)
4. Save and wait for deployment.
5. Your live URL will be:
   - `https://YOUR_GITHUB_USERNAME.github.io/luxury-product-page/`
