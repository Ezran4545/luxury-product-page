# Luxury Product Page

A modern, responsive e-commerce product page for a luxury watch brand, built with vanilla HTML, CSS, and JavaScript.

## Live View

[View Live Demo](https://ezran4545.github.io/luxury-product-page/)



## Features

- Premium product page layout and typography
- Dark/light theme toggle
- Interactive image gallery with popup lightbox
- Zoom controls, wheel zoom, pinch-to-zoom, and drag-to-pan
- Product variants (size and color chips)
- Add-to-cart interactions with quantity sync (desktop/mobile)
- Sticky mobile buy bar
- Sticky mini-cart summary with subtotal
- Wishlist toggle
- Reviews section with rating filters
- Recently viewed products section

## Project Structure

- `index.html` - page structure
- `styles.css` - all styling and responsive rules
- `script.js` - interactivity and UI behavior
